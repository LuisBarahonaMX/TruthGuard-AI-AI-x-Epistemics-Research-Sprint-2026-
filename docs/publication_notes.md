# Notas para el editor de la publicacion

Este directorio es una COPIA de distribucion. El proyecto de origen se mantiene intacto.
Se excluyeron temporalmente los paquetes duplicados, backups, experimentos piloto
anteriores y ficheros de recuperacion. No significa que deban borrarse del origen.
El contenido curado de scientific_v3 se mantiene porque es necesario para explicar
la cadena de adjudicaciones de los 96 casos.

Antes de publicar: documentar dependencias reales, licencia, autoria, limitaciones,
y comprobar si los textos JSONL o CSV contienen datos privados o secretos.
